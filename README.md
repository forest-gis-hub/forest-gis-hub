# Forest GIS Hub — Homepage v1.0

森林・林業・GISに関する情報を発信する個人運営サイトのトップページです。

## ローカルで確認
1. このフォルダを展開します。
2. `index.html` をブラウザで開きます。
3. Google Fonts と Unsplash の画像を利用しているため、初回表示にはインターネット接続が必要です。

## 公開前に必ず変更する箇所
- `info@example.com` を実際に管理できる問い合わせ先に変更するか、問い合わせ導線を一旦削除してください。
- 記事カードはサンプルです。公開前に実際の記事に差し替えるか、「準備中」と明記してください。
- 使用する画像のライセンス・利用条件を公開前に確認してください。現在の画像はUnsplashの画像URLを参照しています。
- 運営者情報、プライバシーポリシー、免責事項、データ利用条件を必要に応じて追加してください。
- 職場の非公開情報、個人情報、許可を得ていない森林・林道情報は掲載しないでください。

## Cloudflare Pagesで公開する場合
1. GitHubにこのフォルダの内容を含むリポジトリを作成してpushします。
2. CloudflareのPagesからGitHubリポジトリを接続します。
3. フレームワークプリセットは「None」、ビルドコマンドは空欄、出力ディレクトリは `/`（リポジトリ直下）に設定します。
4. デプロイ後に発行されるURLで表示を確認します。

このサイトは静的HTML/CSS/JavaScriptです。現段階では記事投稿管理、ユーザー登録、独自タイル配信サーバーは含みません。
