QGISのインストール方法｜初心者向けにダウンロードから起動まで解説

公開準備中

QGISを使い始めるには、まずパソコンにソフトウェアをインストールします。この記事ではWindowsを使う初心者に向けて、公式サイトでの入手から最初の起動までを順番に紹介します。

1. インストールする前に

QGISは無料で利用できる地理情報システム（GIS）ソフトウェアです。地図を表示したり、位置情報を持つデータを重ね合わせたりできます。

この記事ではWindows版を中心に説明します。インストールには、ソフトウェアを保存できる空き容量とインターネット接続が必要です。職場や学校の管理パソコンでは、インストール権限が制限されている場合があります。

ポイント：検索結果に表示された非公式の配布サイトではなく、必ずQGISの公式サイトから入手しましょう。

2. QGIS公式サイトからダウンロードする

ブラウザでQGIS公式サイトを開き、ダウンロードページへ進みます。ダウンロード画面の表示やボタン名は、公式サイトの更新により変わることがあります。

  1. 公式サイトを開く。
  2. 「Download（ダウンロード）」の案内を選ぶ。
  3. Windows向けのインストーラーを探す。
  4. 利用したいバージョンのインストーラーをダウンロードする。

MacやLinuxを使っている場合も、同じ公式ダウンロードページから対応する案内を確認できます。

3. QGISのバージョンはどれを選ぶ？

ダウンロードページでは、通常のリリース版とLTR（Long Term Release：長期サポート版）が案内される場合があります。

通常のリリース版

比較的新しい機能や改善を利用したい方向けです。

LTR（長期サポート版）

安定性を重視して利用したい場合の選択肢です。はじめて学習する人で特別な指定がなければ、LTRを選ぶと進めやすいでしょう。

学校や職場で使用する場合は、教材や組織で指定されたバージョンを優先してください。画面の構成や機能名はバージョンによって異なることがあります。

4. WindowsにQGISをインストールする

ダウンロードしたインストーラーを実行します。以下は一般的な手順です。実際の画面や選択項目は配布形式やバージョンによって異なります。

  1. ダウンロードしたインストーラーファイルをダブルクリックする。
  2. Windowsの確認画面が表示されたら、配布元を確認して操作を続ける。
  3. セットアップ画面の案内を読み、必要な項目を選択する。
  4. インストール先などに特別な理由がなければ、標準設定を基本に進める。
  5. インストール完了の表示を確認し、セットアップを終了する。
注意：インストールの途中で管理者権限を求められる場合があります。管理対象のパソコンでは、無理に設定を変更せず管理者に確認してください。

5. QGISを起動して確認する

WindowsのスタートメニューなどからQGISを探して起動します。初回は起動まで少し時間がかかる場合があります。

地図を表示する広い領域や、レイヤを管理するパネル、メニュー・ツールバーなどが見えれば、基本的な起動確認は完了です。この段階で地図が表示されていなくても問題ありません。地図データは次回以降の記事で読み込みます。

6. よくある疑問と対処法

QGISは無料で使える？

はい。QGISはオープンソースソフトウェアで、無料で利用できます。

ダウンロードしたファイルが見つからない

ブラウザのダウンロード履歴や、Windowsの「ダウンロード」フォルダを確認しましょう。

インストールできない

Windowsのバージョンやパソコンの管理権限、空き容量、ダウンロードの完了状況を確認してください。詳細な要件は公式ダウンロードページの案内を参照しましょう。

古いQGISが入っている

既存の環境やプラグインを使っている場合は、安易に削除せず、利用中のバージョンと新しいバージョンの扱いを確認してください。

7. まとめ

QGISを使い始めるための流れは、公式サイトでダウンロード → インストール → 起動確認の3段階です。まずはQGISが起動するところまで進めれば十分です。
